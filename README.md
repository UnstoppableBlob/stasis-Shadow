# Stasis Shadow

## What is it?

This is a robotic arm I made that uses servos, and has 5 axes! It's mainly controlled using a special glove with a gyroscope on it.

## How we made it

This is made using the MPU_Light library by rfetick, and also uses the WiFiUDP library from Arduino IDE. We also have a telegraph that is being used as a switch, and that controls the grabbing mechanism.

## How to Use it

You can use this by putting on the glove. If you want to rotate the arm, then you can make your index and thumb touch, and rotate either pitch or yaw. Yaw will move it left/right, and the pitch will increase/decrease distance away from base. Click the black button on the telegraph to open/close the grabber.
